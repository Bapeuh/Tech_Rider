# Backlight Tech Riders

Ce dépôt centralise les fiches techniques (Tech Riders) des expériences Backlight en français et en anglais.

## Structure

Chaque expérience possède son propre dossier avec deux fichiers Markdown :

- `FR.md` — version française
- `EN.md` — English version

## Expériences

- La Magie Opéra
- Lady Liberty
- Amsterdam
- La Danse des Océans
- Eclipse
- Ascenders
- Icecube Protocol
- Toyland
